# The evening forum's script: tools/forum.py turns it into src/gen/forumtxt.asm.
#
# Swapping in an AtariAge member's name is one line in @user (handle and
# tag). Limits (checked by the tool): a handle 12 characters, a tag 22, a
# thread title 38, a post line 35, a post 4 lines, a review phrase 35.
# Text is ASCII 32-95: upper case, digits and punctuation.
#
# @user  key  HANDLE  palette  avatar  | tag
#   palettes: 3 blue, 4 magenta, 5 orange, 6 green, 7 violet
# @day N  | the evening's name ; @game | the slop ROM's title
# @thread key [release] | title          (release: the slop ROM's thread)
# @post key                              (then its lines)
# @phrase slot day [only] [kind] [bug N] | text
#   slot: opener, bugs, verdict. day: the first day it's offered (only:
#   and only that day). kind: a
#   constructive one (counted for the finale). bug N: only if Arthur saw
#   that bug (seenbugs bit N: 1 zone ghosts, 2 zone clipping, 4 no holey
#   DMA, 8 DMA overrun, 16 not BCD, 32 the overflow).
# @after day [kind] key                  (a reply to Arthur's review)
