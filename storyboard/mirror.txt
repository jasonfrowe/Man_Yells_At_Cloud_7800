# tools/mirror.py turns it into src/gen/mirrordat.asm (bank 6).

# @room key | NAME             a room: then @pal, its 11 map rows, doors, NPC
#   @pal  c1 c2 c3 (x4)        palettes 4-7 (floor, walls, furniture, tech)
#   @bg   colour               the background (under the grid), default $00
#   map rows: 20 characters, screen rows 1-11 (the legend below)
#   @door col row room col row a TV (its left half) to another room: where
#                              you step out (the tile you stand on)
#   @npc key col row           who stands here (sue, hal, maria, pixelkid)
#
# Map legend: walkable  . floor  ~ rug  , grid  p plate  d door (open)
#             solid     # wall top  = wall  w window  P poster  T t TV
#                       [ - ] couch  h armchair  o table  B shelf
#                       W workbench  A a arcade cabinet  S rack  D door
#                       R r Q q card reader  L lever  * plant  l lamp
#
# @talk N key                   dialogue N (mirror.bas uses the numbers)
#   = SPEAKER                   who's talking (up to 20 characters)
#   then pages of 1-2 lines (20 characters), a blank line between pages
